# Shell NFT DAPP

A reproducible Shell-native NFT dApp for testing Shell Chain smart contract deployment and interaction.

This project intentionally uses a Shell-native NFT contract instead of claiming ERC-721 compatibility. Shell Chain canonical addresses are 32-byte `0x` values, while ERC-721 assumes 20-byte `address` values.

## Prerequisites

- Node.js 20+
- A running Shell Chain node at `http://127.0.0.1:8545`
- A funded Shell keystore generated by `shell-node key generate`

Start the local node with CORS enabled for the browser UI:

```bash
shell-node run \
  --datadir shell-data \
  --keystore my-key.json \
  --password-file .quickstart-password \
  --rpc-addr 127.0.0.1:8545 \
  --rpc-cors "http://127.0.0.1:5173,http://localhost:5173" \
  --block-time 2000 \
  --max-idle-interval 0 \
  --network dev \
  --rpc-api eth,net,web3,shell
```

## Setup

```bash
npm ci
cp .env.example .env
```

Edit `.env`:

```bash
SHELL_RPC_URL=http://127.0.0.1:8545
SHELL_CHAIN_ID=1337
SHELL_KEYSTORE_PATH=../shell-chain/my-key.json
SHELL_KEYSTORE_PASSWORD=dev-password
NFT_BASE_URI=ipfs://example/
```

## CLI flow

```bash
npm run compile
npm run smoke
```

The smoke test deploys `ShellNft`, mints token `1` to the signer address, then verifies `totalSupply`, `ownerOf(1)`, and `tokenURI(1)` through `eth_call`.

Individual commands:

```bash
npm run deploy
npm run mint -- ipfs://example/shell-nft-1.json
npm run read -- 1
```

## Browser flow

```bash
npm run compile
npm run dev
```

Open `http://127.0.0.1:5173`, paste your keystore JSON, password, and compiled bytecode from `artifacts/ShellNft.compiled.json`, then deploy and mint.
